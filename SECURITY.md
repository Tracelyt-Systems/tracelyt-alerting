# Security Policy

The Tracelyt Systems maintainers take the security of `tracelyt-alerting` and user observability environments seriously.

---

## Supported Versions

In this initial foundation phase, development takes place on the `main` branch.

| Version | Supported |
|---|---|
| `0.1.0-SNAPSHOT` (`main`) | :white_check_mark: |
| Earlier versions | :x: |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

To report a vulnerability:
1. Navigate to the **Security** tab of the [`tracelyt-alerting`](https://github.com/Tracelyt-Systems/tracelyt-alerting) repository on GitHub.
2. Click **Report a vulnerability** to open an advisory draft using GitHub Private Vulnerability Reporting.
3. Provide a clear description, reproduction steps, and potential impact.

Maintainers will review the report privately, acknowledge receipt, investigate the root cause, and coordinate a patch release.
